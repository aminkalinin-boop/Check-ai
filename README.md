# Проверка DOCX на ИИ

Веб-приложение для проверки документов Word на признаки применения генеративного ИИ. Открывается в браузере на телефоне и на компьютере; документ разбирается прямо в браузере и никуда не отправляется.

## Что проверяется

1. Технические следы: стили и классы веб-интерфейсов нейросетей (DeepSeek, ChatGPT, Claude, Gemini / AI Studio, Qwen, GigaChat и др.), Angular, Tailwind, KaTeX, вставки HTML, ссылки через переадресацию Google, метки `utm_source` нейросетей, метки C2PA в изображениях, метаданные файла.
2. Невидимые символы, остатки Markdown и LaTeX, реплики чат-ботов, смешение типографики тире.
3. Рисунки: собрана ли схема из фигур Word или вставлена цельной картинкой.
4. Содержание: чужеродная тематика, повторы числовых структур, категоричные выводы, соответствие ссылок и списка литературы, опечатки и терминология.
5. Стилометрический профиль (лексика LLM и шаблонность) с ориентирами, откалиброванными на AINL-Eval 2025.

Результаты вероятностные: признак показывает, что текст проходил через сервис или веб-страницу, но не устанавливает авторство.

## Структура

- `index.html` — собранное приложение (публикуется через GitHub Pages).
- `src/` — исходники; после правок выполнить `python3 build.py`.
- `vendor/` — JSZip 3.10.1 (MIT).
- `data/` — обезличенные числовые профили для калибровки. Исходные тексты корпусов в репозиторий не добавляются.
