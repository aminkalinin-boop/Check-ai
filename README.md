# Проверка DOCX на ИИ

Веб-приложение для проверки документов Word на признаки применения генеративного ИИ. Открывается в браузере на телефоне и на компьютере. В офлайн-режиме весь анализ выполняется локально. В онлайн-режиме исходный DOCX также разбирается локально; только после согласия отдельные фрагменты или библиографические записи могут передаваться внешним сервисам.

## Что проверяется

1. Технические следы: стили и классы веб-интерфейсов нейросетей (DeepSeek, ChatGPT, Claude, Gemini / AI Studio, Qwen, GigaChat и др.), Angular, Tailwind, KaTeX, вставки HTML, ссылки через переадресацию Google, метки `utm_source` нейросетей, метки C2PA в изображениях, метаданные файла.
2. Невидимые символы, остатки Markdown и LaTeX, реплики чат-ботов, смешение типографики тире.
3. Рисунки: собрана ли схема из фигур Word или вставлена цельной картинкой.
4. Содержание: чужеродная тематика, повторы числовых структур, категоричные выводы, соответствие ссылок и списка литературы, опечатки и терминология.
5. Стилометрический профиль (лексика LLM и шаблонность) с ориентирами, откалиброванными на AINL-Eval 2025.

Результаты вероятностные: признак показывает, что текст проходил через сервис или веб-страницу, но не устанавливает авторство.

## Структура

- `index.html` — собранное приложение (публикуется через GitHub Pages).
- `src/` — исходники; после правок выполнить `python3 build.py`.
- `vendor/` — JSZip 3.10.1 (MIT).
- `data/` — обезличенные числовые профили для калибровки. Исходные тексты корпусов в репозиторий не добавляются.


## Один интерфейс — режимы «Офлайн / Онлайн»

Сайт: https://aminkalinin-boop.github.io/Check-ai/ . Для обычной работы **не нужно вводить адрес сервера или ключ**. В офлайн-режиме доступны встроенные словари, технические и стилометрические правила и экспорт DOCX. Локальный реестр этапов и сценариев находится в `src/offline_engine.js` и выводится во вкладке «Метаданные». Однофайловая автономная версия доступна среди артефактов GitHub Actions (`Check-AI-Offline`).

В онлайн-режиме сначала выполняется то же самое ядро; затем автоматически сверяется библиография по Crossref и, **только при подключённом защищённом API-сервере**, отдельно исследуются логические противоречия и источники с помощью языковой модели. До серверного подключения модель **не работает**, и программа честно указывает этот факт. Никакой API-ключ на клиенте не хранится. Инструкции администратору: [DUAL_MODE.md](DUAL_MODE.md).


## Дополнительная проверка по заранее выделенным фрагментам

В интерфейсе перед загрузкой DOCX включите **«Проверить заранее выделенные фрагменты из отчёта „Антиплагиат“»** и выберите цвет. Выделенные Word-маркером или заливкой области анализируются отдельно от собственных признаков Check-AI. Во вкладке **«Разметка Антиплагиата»** доступны текст выделения, контекст, сравнение с локальными находками, проблема и предметное действие по проверке; результаты также добавляются в приложение к Word-заключению и в комментарии копии DOCX. Исходные цвета сохраняются. Это исследовательская функция, а не способ подтверждения авторства по цвету. Инструкция: [research/MANUAL_HIGHLIGHTS_GUIDE.md](research/MANUAL_HIGHLIGHTS_GUIDE.md).
